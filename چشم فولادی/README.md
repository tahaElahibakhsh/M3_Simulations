# چشمِ فولادی

بازطراحی تمرینی Q3 آزمون عملی مرحلهٔ سوم ۱۴۰۵ برای دسته‌بندی بافت عیوب فولاد، استخراج ویژگی‌های دستی و آموزش MLP روی CPU. از آرشیو برچسب‌دار ۱۱۵۲ تصویری، splitهای طبقه‌بندی‌شده ساخته شده‌اند.

- `question.ipynb`: صورت سؤال
- `solution.ipynb`: پاسخ مرجع با مارک‌داون‌های یکسان
- `data/train/train_data.npz`: ۸۰۴ تصویر برچسب‌دار
- `data/validation/validation_data.npz`: ۱۷۴ تصویر برچسب‌دار
- `data/test/test_images.npz`: ۱۷۴ تصویر test بدون برچسب
- `private/test_labels.npz`: برچسب‌های test برای برگزارکننده

آرایه‌های `images`, `labels`, `class_names`, `ids` داخل NPZها قرار دارند؛ فایل test برچسب ندارد. پوشهٔ `private/` و `solution.ipynb` را به شرکت‌کنندگان ندهید. فایل test اصلی ۲۸۸ تصویری آزمون پارسال، چون برچسب آن همراه منابع نبود، در این جاج تمرینی به‌کار نرفته است.
