# فرودِ جعبه‌ی سیاه

تسک رگرسیون سطح ۱ برای تمرین مهندسی ویژگی و پیاده‌سازی رگرسیون خطی با NumPy.

- `question.ipynb`: دفترچهٔ شرکت‌کننده
- `data/train/train.csv`: دادهٔ برچسب‌دار آموزش
- `data/validation/validation.csv`: دادهٔ برچسب‌دار اعتبارسنجی
- `data/test/test.csv`: ورودی آزمون بدون برچسب
- `private/test_labels.csv`: برچسب‌های test؛ محرمانه و خارج از بستهٔ شرکت‌کننده
- `private/reference_solution.py`: راه‌حل مرجع برگزارکننده

**پیش از انتشار:** پوشهٔ `private/` را از بستهٔ شرکت‌کنندگان جدا کنید.
