# بازمانده‌های دیوار

تمرین سطح ۲ برای طبقه‌بندی دودویی با لجستیک‌رگرشن از صفر و مهندسی ویژگی هندسی. روایت کنسرت و بلیت‌ها داستانی است؛ دادهٔ پایه از دیتاست Raisin مخزن UCI آمده است.

منبع: https://archive.ics.uci.edu/dataset/850/raisin

Çinar, İ., Koklu, M., & Tasdemir, S. (2020), Classification of Raisin Grains Using Machine Vision and Artificial Intelligence Methods, DOI: https://doi.org/10.30855/gmbd.2020.03.03. دیتاست ۹۰۰ نمونه، دو کلاس متوازن و هفت ویژگی ریخت‌شناسی دارد و تحت مجوز CC BY 4.0 منتشر شده است. برچسب‌ها به 0 و 1 تبدیل شده‌اند. فایل‌های train/validation/test با seed ثابت و جداسازی طبقه‌بندی‌شده ساخته شده‌اند؛ برچسب‌های test در private/test_labels.csv هستند.
