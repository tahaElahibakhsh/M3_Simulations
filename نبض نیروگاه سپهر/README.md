# نبضِ نیروگاه سپهر

بازطراحی تمرینی Q1 آزمون عملی مرحلهٔ سوم ۱۴۰۵ در قالب مجموعهٔ آزمون‌های آزمایشی. داده از فایل آموزش همان سؤال آمده و به سه بخش مستقل تقسیم شده است.

- `question.ipynb`: صورت سؤال
- `solution.ipynb`: پاسخ مرجع با مارک‌داون‌های یکسان
- `data/train/train.csv`: ۱۴۰۰ ردیف آموزش
- `data/validation/validation.csv`: ۳۰۰ ردیف اعتبارسنجی
- `data/test/test.csv`: ۳۰۰ ردیف test بدون برچسب
- `private/test_labels.csv`: برچسب test برای برگزارکننده

پوشهٔ `private/` و `solution.ipynb` را در اختیار شرکت‌کنندگان قرار ندهید.
