# مهرهای فراموش‌شدهٔ سلطنتی

بازطراحیِ تمرینیِ «The Lattice of Forgotten Parity» از Creative ML Tasks، با روایت کتابخانهٔ سلطنتی. دادهٔ اصلی شامل ۲۰۰۰ مختصات دوبعدی و برچسب زوج‌وفرد است.

- `question.ipynb`: صورت سؤال و تابع مشاهدهٔ سه‌بعدی فضای ویژگی
- `solution.ipynb`: پاسخ مرجع با همان مارک‌داون‌ها
- `data/train/train.csv`: آموزش برچسب‌دار
- `data/validation/validation.csv`: اعتبارسنجی برچسب‌دار
- `data/test/test.csv`: ورودی آزمون بدون برچسب
- `private/test_labels.csv`: برچسب test برای برگزارکننده

قانون هندسی الگو در solution پیاده شده است. پوشهٔ `private/` و `solution.ipynb` را به شرکت‌کنندگان ندهید.
