# ردپای سایه‌ها

بازطراحی تمرینی Q2 آزمون عملی مرحلهٔ سوم ۱۴۰۵، با تمرکز بر KNN، PCA و ارزیابی دادهٔ نامتوازن. داده‌های برچسب‌دار منبع به splitهای مستقل تقسیم شده‌اند.

- `question.ipynb`: صورت سؤال
- `solution.ipynb`: پاسخ مرجع با مارک‌داون‌های یکسان
- `data/train/train.csv`: ۱۶۸۰ ردیف آموزش
- `data/validation/validation.csv`: ۳۶۰ ردیف اعتبارسنجی
- `data/test/test.csv`: ۳۶۰ ردیف بدون برچسب
- `private/test_labels.csv`: برچسب test برای برگزارکننده

پوشهٔ `private/` و `solution.ipynb` را در بستهٔ شرکت‌کننده قرار ندهید.
